# Changelog

All notable changes to docuconf for Rust (`docuconf` and `docuconf-derive`) are documented here. Entries after
0.1.0 are generated by [release-please](https://github.com/googleapis/release-please) from Conventional Commit
messages; see [CONTRIBUTING.md](CONTRIBUTING.md).

## 0.1.0

First version: typed configuration contracts for [figment](https://docs.rs/figment) and serde, implementing spec
`v1alpha1`. Both crates share one version and are released together.

### Features

* `#[derive(Docuconf)]` and `#[derive(DocuconfEnum)]` on serde config structs: descriptions, secrets, constraints,
  URL schemes, durations, list bounds (`itemMin`/`itemMax`) and file inputs.
* Boot validation of environment variables, figment config files and profiles, and file inputs (TLS key pairs, CA
  bundles, PKCS#12 keystores, JSON/YAML/TOML config files, text and binary files) that reports every violation at
  once with stable error codes.
* Contract export, config-file overlays, contract-first mode and the shared conformance runner.
* The `orders` example service.
